The first release of Perfect Dark: Recompiled for Windows and Linux: a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release's second revision (*Perfect Dark (U) (V1.1)*, a big-endian `.z64` of 32 MiB, MD5 `e03b088b6ac9e0080440efed07c1e40f`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `PerfectDarkRecompiled-v0.1.0-windows-x64.zip` and run `PerfectDarkRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `PerfectDarkRecompiled-v0.1.0-linux-x64.tar.gz` and run `PerfectDarkRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**What works:** the menus, agent files saved and loaded across restarts, missions from the briefing to the end screen with sound, at 59-60 frames a second in the levels, interpolated to the display's rate.

**Enhancements**, each an option in the settings menu with an Original value that plays as the console does:

- High resolution at the window's size, with 2× MSAA
- Smooth motion at the display's refresh rate
- Widescreen 3D and HUD
- Field of view from 70 to 100 degrees
- Mouse look and aim
- Keyboard and gamepad controls, rebindable

**Not checked yet:** long play sessions, rumble on a pad, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The [README](https://github.com/n64hub/perfect-dark-recomp#readme) has every setting and what is still wrong; [docs/building.md](https://github.com/n64hub/perfect-dark-recomp/blob/main/docs/building.md) says how to build it yourself.
